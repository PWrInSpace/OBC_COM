static uint32_t FindPage ( EE_Find_type  Operation)
static

Find suitable page for read/write/erase operation.

It also update pages state if current page is full. And it force cleanup if all pages are full.

Parameters
OperationType of page to be requested. This parameter can be one of the following values:
  • FIND_READ_PAGE return the active page index
  • FIND_WRITE_PAGE return the write page index
  • FIND_ERASE_PAGE return the erase page index
Return values
Page_Index
  • Page Index: on success
  • EE_NO_PAGE_FOUND : if an error occurs
