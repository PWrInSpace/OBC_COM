Detailed Description

Represents an amount of time measurable by the radio clock.

Time = Step * NbSteps
Example:
Step = RADIO_TICK_SIZE_4000_US( 4 ms )
NbSteps = 1000
Time = 4e-3 * 1000 = 4 seconds
